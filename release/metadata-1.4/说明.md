### 0.1 这个结构现在会怎么伤转化

用户路径是这样的：

```
列表行看到 $9.99 → 点进产品页 → 产品页写着「App 内购买项目 $27.99」
→ 决定付款 $9.99 → 用满 5 场会 → 第 6 场界面显示「会议失败 / Free plan limit」
```

三处漏损，按严重程度排：

1. **花了两笔钱才拿全**：$9.99 + $27.99 = **$37.98**。产品页把 $27.99 摊开在
   「App 内购买项目」里，所以这不只是列表层的问题，**它正好压在「产品页 → 下载」
   这一层——也就是截图起作用的那一层。**
2. **$9.99 买到的核心功能是限月的**。AI 纪要是这个 App 的主张，被限到 5 次/月，
   等于付费用户买到的是一个试用品。
3. **撞墙不是弹窗提醒，是「会议失败」**。`status = "failed"` + 摘要 `Free plan limit`，
   用户看到的是自己刚开完的会被判失败。这是退款和 1 星的高发路径。

这解释了为什么改首图没用——但也说明**光靠文案也救不了**，0.3 是三条真正的解法。

### 0.2 文案里为什么不写具体金额

描述里一旦写死 `$9.99` / `$27.99`，175 个国家和地区的价格全不一样，改价时文案就假了；
苹果也不鼓励在描述里报价。所以四语描述只写**结构**（哪些含、哪些要买、是不是订阅），
金额交给价格牌和「App 内购买项目」列表自动显示。

## 4. 定价实验：这次要动的不是一个数字，是结构

`ASC → 我的 App → KinetMinutes → 价格与销售范围 → 价格 → 更改价格`

先记录基线（App Analytics 近 14 天）：**展现次数**、**产品页浏览**、
两者相除的 CTR、**首次下载**、以及**内购转化**（Pro 购买数 / 首次下载）。

然后只动一个变量，跑两周。

判断口径：

- **改价后 CTR 上升、下载也上升** → 价格是主要阻力。
- **CTR 上升、下载没动** → 点击被吸引进来但产品页没接住，问题在截图/$27.99 那一栏。
- **CTR 没动** → 阻力在评分（0 条）和认知，回到副标题与评价获取。

⚠️ 0 评分状态下样本本来就小，**百分比波动不要当结论**；两周窗口 + 绝对量一起看。

## 6. 顺手修掉的一个真 bug（已改代码，未打包）

`LibraryWindowController.show(meeting:)` 里拼会议头部那行：

```swift
let df = DateFormatter(); df.dateStyle = .medium; df.timeStyle = .short   // 没有 locale
meta += " · " + (mins >= 1 ? "\(mins) 分钟" : "\(Int(m.durationSeconds)) 秒")   // 写死中文
```

后果不只是截图难看：**英文和日文用户在自己的会议列表里看到的就是「2026年10月15日 · 30 分钟」。**
一个 $9.99 的付费 app，这种瑕疵会被直接写进差评。

改动（5 处 + 2 个文案键）：

| 文件 | 改动 |
|---|---|
| `L10n.swift` | 新增 `static var locale` = `Locale(identifier: preferredLanguage())` |
| `LibraryWindowController.swift:251` | 侧边栏列表的日期格式器加 `f.locale` |
| `LibraryWindowController.swift:401` | 详情头日期加 `df.locale`，分钟/秒改用 `L10n.string("Minutes"/"Seconds")` |
| `StatsPane.swift:142` | "Updated" 时间加 `f.locale` |
| `MeetingStore.swift:510` | 默认会议标题的日期加 `f.locale` |
| `Resources/L10n.json` | 四语新增 `Seconds`（en `s`、zh-Hans `秒`、zh-Hant `秒`、ja `秒`） |

未动 `Exporters.swift`：那里用的是固定格式 `yyyy-MM-dd HH:mm`，纯数字，跨语言安全，动它反而会改变导出文件格式。

编译验证：`xcodebuild ... OTHER_SWIFT_FLAGS='-disable-sandbox'` → **BUILD SUCCEEDED**。
`L10n.json` 四语均为 140 键，机器校验通过；UI 里已无写死的「分钟 / 秒」。

⚠️ 这需要一次新构建（build 9）才能进商店截图。**我没有在运行的 app 里肉眼确认过渲染结果**，
确认方式是下一步重截 raw 时直接看。
