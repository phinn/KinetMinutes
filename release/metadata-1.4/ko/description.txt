KinetMinutes는 회의를 구조화된 회의록으로 바꿉니다. 자동으로, 사적으로, 그리고 전부 이 Mac 안에서.

감지 · 녹음 · 회의록
Zoom, Tencent Meeting, Teams, Lark(Feishu), DingTalk, Discord, Webex에서 통화를 시작하면 KinetMinutes가 자동으로 녹음을 시작합니다. 회의가 끝나면 로컬 AI가 회의록을 작성합니다. 명확한 요약, 합의된 결정 사항, 담당자와 마감일이 붙은 할 일까지. "저장" 버튼도, 업로드도 필요 없습니다.

프라이버시를 위해 만들어졌습니다
• 100% 온디바이스: Whisper 받아쓰기와 AI 요약이 모두 로컬에서 실행됩니다
• 오디오와 회의록에 대한 네트워크 통신 제로 — 완전히 오프라인으로 동작
• 오디오·받아쓰기·회의록은 내 라이브러리에 저장되고, 언제든 전부 삭제할 수 있습니다
• 면접, 고객 협상, 법무, 전략 회의에 적합

받아쓰기가 아니라 회의록
• 요약 — 몇 문장으로 회의 파악
• 결정 사항 — 실제로 합의한 내용
• 할 일 — 담당자와 마감일이 붙은 작업
• 타임라인 — 타임스탬프가 붙은 핵심 지점, 클릭하면 해당 지점으로 이동
• 필요할 때는 전체 받아쓰기까지

중국어와 영어가 섞여도 강합니다
보통화 + 영어 코드 스위칭에 최적화되어, 글로벌 도구들이 비워 둔 부분을 채웁니다. Whisper 모델은 한 번 내려받으면 이후 오프라인으로 동작합니다.

회의 보관함
모든 회의를 회의록과 받아쓰기 전체에서 검색할 수 있습니다. 소스 앱별 정리, 내보내기 지원.

앱에 포함된 것
• 녹음과 오프라인 받아쓰기 무제한 — 월 횟수 제한 없음
• Whisper 모델 4종 모두 (base 150 MB ~ large-v3 3 GB)
• 회의 보관함 전체 기능: 검색, 태그, Markdown / TXT / SRT 내보내기
• AI 회의록은 달력 월 5회

KinetMinutes Pro — 선택 사항, 1회 구매
Pro는 월 회의록 횟수 제한을 없앱니다. AI 회의록 무제한, 앱은 그대로, 파일도 로컬 그대로. 구독이 아닌 앱 내 1회 구매이며 계정을 만들 필요가 없습니다. 업그레이드하지 않아도 이미 녹음한 회의는 계속 사용할 수 있습니다.

메뉴 막대 네이티브
메뉴 막대에 상주합니다. 로그인 시 자동 실행은 선택 사항. Electron도, 브라우저 엔진도 없는 네이티브 macOS 디자인.

이런 분께
• 회의록을 팀에 공유하는 컨설턴트·영업·고객 성공 담당자
• 주간 싱크와 1:1을 운영하는 매니저
• 클라우드 녹음이 허용되지 않는 인사·면접관
• 취재 기록을 남기는 기자·연구자

당신의 회의는 당신의 것입니다. KinetMinutes는 그렇게 지킵니다.
